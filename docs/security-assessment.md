# セキュリティ診断・改修記録

基準: OWASP ASVS 5.0 Level 2、OWASP Web Security Testing Guide

## 対象と方法

- Reactクライアント、PHP API、SQLiteスキーマ、配布物を対象にコードレビューを実施。
- ローカル隔離環境で認証、セッション、Origin、CSRF、Content-Type、廃止APIをHTTP経由で能動試験。
- 公開環境には破壊・大量送信・認証試行を行わず、HTTP応答と公開ファイルだけを受動確認。
- npm依存関係の既知脆弱性監査、PHP全ファイルの構文検査、配布物の秘密情報混入検査を実施。

## 修正した事項

| 重要度 | 事項                                                            | 対応                                                     |
| ------ | --------------------------------------------------------------- | -------------------------------------------------------- |
| 高     | HTTPアクセスがHTTPSへ強制されない                               | `.htaccess`で同一URLのHTTPSへ308転送                     |
| 高     | 管理者専用運用にもかかわらず一般登録・パスワード再設定APIが残存 | 登録、確認、再設定APIとメール送信依存を削除              |
| 高     | 状態変更APIの送信元検証がCSRFトークンだけ                       | `Origin`の完全一致検証を追加                             |
| 中     | セッションにアイドル期限と同時利用数上限がない                  | アイドル12時間、絶対30日、1利用者5セッションに制限       |
| 中     | ログイン制限が送信元IPだけ                                      | IPとログインIDハッシュの組、およびIP全体で15分単位に制限 |
| 中     | 不明なIDと既存IDでパスワード検証コストが異なる                  | 不明IDでもダミーハッシュを検証し、応答を統一             |
| 中     | JSON本文に明示的な上限がない                                    | 64KiB上限と`application/json`必須化                      |
| 中     | 開発用Vitest依存に既知の任意ファイル読み取り問題                | 修正版Vitest 5へ更新                                     |
| 低     | 管理者パスワード同期が通常リクエスト時にも起こり得る            | 明示的な`bin/sync-admin.php`へ分離                       |
| 低     | APIクライアントが単一ファイルに集中                             | transport/auth/charts/settingsへ責務分割                 |

## 自動確認

- フロントエンドの型検査、ESLint、Vitest。
- PHP全ファイルの構文検査と8世代のマイグレーション試験。
- HTTPセキュリティスモーク試験: 廃止API 404、不正ログイン401、Cookie属性、Origin 403、CSRF 419、正常作成201、非JSON 415、最大5セッション。
- 配布物検査: `.env`、SQLite本体・WAL・SHM、テスト、開発専用ファイルを除外。

## 残存リスクと運用事項

- 共有ホスティングを利用する場合、WAF、OS、Apache、PHP本体は提供事業者の管理範囲となる。利用可能なWAFと自動バックアップを有効にする。
- CSPは既存インラインスタイルとの互換性のため`style-src 'unsafe-inline'`を維持。将来CSS-in-JSを廃止できた時点でnonce/hash方式を検討する。
- レート制限はSQLiteベース。複数サーバー構成へ移行する場合は共有ストアへ変更する。
- 本番での能動的侵入試験は実施していない。実施時は書面の許可、対象範囲、時間帯、停止条件、バックアップを別途定める。
- `.env`とSQLiteファイルは公開ディレクトリ外へ置き、FTP配布では上書きしない。

## 配置後の確認項目

- HTTPからHTTPSへ転送されること。
- 画面と静的アセットが正常に配信されること。
- 未認証のセッションAPIが401を返すこと。
- `.env`とSQLiteへ外部から直接アクセスできないこと。
